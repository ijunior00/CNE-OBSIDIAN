# 🗺️ CNE-OBSIDIAN — Segundo Cérebro de *Poké Aventura* (Kanto, Pokémon 5e)

Este repositório **é um vault do Obsidian**. Ele guarda o mundo vivo da nossa campanha de mesa: personagens, organizações, locais, Pokémon, itens, quests e o registro de cada sessão — tudo em Markdown e interligado por `[[wikilinks]]`.

A ideia central: **Obsidian ⇄ GitHub**. Você escreve e lê no Obsidian; eu (Claude) leio e atualizo os mesmos arquivos aqui no GitHub a partir das nossas conversas. Cada lado sincroniza com o outro.

> Campanha: **Coroa Negra Eterna (CNE)** — uma jornada Pokémon clássica em Kanto com uma conspiração crescente por baixo.

---

## Como começar (leia isto primeiro)

1. **Conecte o Obsidian a este repositório** → siga o guia [`00 - Sistema/Como Conectar Obsidian ao GitHub.md`](<00 - Sistema/Como Conectar Obsidian ao GitHub.md>).
2. **Entenda o fluxo de atualização** (como eu atualizo o mundo a partir das conversas) → [`00 - Sistema/Como Atualizamos o Mundo (Fluxo de Trabalho).md`](<00 - Sistema/Como Atualizamos o Mundo (Fluxo de Trabalho).md>).
3. **Abra a nota inicial** no Obsidian → [`01 - Campanha/🗺️ Mapa do Mundo (MOC).md`](<01 - Campanha/🗺️ Mapa do Mundo (MOC).md>). Ela é o painel central com links para tudo.

Muitas notas contêm **segredos do Mestre** (a verdade sobre a CNE, o Professor Carvalho, Mewtwo). Elas são marcadas com `tags: [spoiler]` e blocos `> [!danger] SEGREDO DO MESTRE`. Se algum jogador for usar este vault, mantenha uma cópia separada sem essas seções.
